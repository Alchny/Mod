# Talismans Mod

A magical Minecraft 1.21.11 Fabric mod that adds talismans granting special effects.

## Features

- **Health Talisman** - Grants Regeneration effect
- **Speed Talisman** - Grants Speed effect  
- **Strength Talisman** - Grants Strength effect
- **Fire Resistance Talisman** - Grants Fire Resistance effect

Simply carry any talisman in your inventory to gain its effect!

## Building

```bash
./gradlew build
```

The built mod JAR will be in `build/libs/`
